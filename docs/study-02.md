# 마음이 프로젝트 2회차 학습 기록

## 오늘 구현한 것

- 채팅 화면 디자인을 개선했다.
- 사용자 메시지를 말풍선으로 만들었다.
- 가짜 AI 답변을 만들었다.
- Enter로 메시지를 전송하도록 만들었다.
- Shift + Enter로 줄바꿈하도록 만들었다.
- 메시지 자동 스크롤을 구현했다.
- DARK 버튼을 구현했다.
- 새 대화 기능을 구현했다.


## 오늘 프로그램의 흐름

사용자가 메시지를 입력한 뒤
마음이의 답변이 나타날 때까지
프로그램에서 어떤 일이 일어나는지
내 말로 적어보기.

1. 사용자가 메세지를 보내면 자바 스크립트가 입력값을 가져간다
2. 그 입력값이 빈 문자열이 아닌지 확인한다. 그리고 messages 배열에 저장한다. (나중에는 ai에게 배열 전달 -> 기억력👍)
(messageInput.value: 입력창에 글을 꺼냄, trim(): 공백을 지움 그런뒤 text에 담음, if(text === ""){ return;}<- 빈문자열인지 아닌지 확인하는거)
3. (빈 문자열이 아닐시) 화면에 사용자 말풍선을 띄운다.
4. 생각중이라는 말이 1초동안 뜬 다음 사라지고 미리 설정해둔 말이 말풍선으로 나타난다. 
5. 마음이의 답변도 messages 배열에 저장된다. 그리고 화면은 가장 최근 말풍선이 보이게 맨 아래로 이동한다.


## 오늘 새롭게 알게 된 개념

### 개념 1
이름: 배열(Array)
내가 이해한 뜻: 여러개의 값을 저장할 수 있는 상자, 근데 칸이 나누어져있어서 순서가 지켜지는 상자 
우리 프로젝트에서 사용된 곳: messages 배열. 사용자와 마음이의 대화를 순서대로 저장한다.

### 개념 2
이름: push()
내가 이해한 뜻: 배열 마지막에 값을 저장해주는 함수
우리 프로젝트에서 사용된 곳: messages.push() 로 적혀 messages 배열에 사용자와 ai말을 순서대로 넣어주는 역할을 한다

### 개념 3
이름: role/content
내가 이해한 뜻: role은 누가 말했는지, content는 무슨 말을 했는지 나타낸다. 이 둘을 { }로 묶어서 메시지 하나를 만든다.
우리 프로젝트에서 사용된 곳: messages 배열 안에 { role, content } 형태로 들어간다. 나중에 API를 연동하면 이 배열이 AI에게 전달되는데, AI 쪽에서 정해둔 형식이 role/content라서 이렇게 쓴다.


### 개념 4
이름: document.createElement()
내가 이해한 뜻: HTML 태그를 새로 하나 만드는 명령. 만들기만 하면 화면에 안 보이고, appendChild로 화면에 붙여야 보인다.
우리 프로젝트에서 사용된 곳: addMessage()에서 말풍선을, showTyping()에서 "마음이가 생각 중..."을 만들 때 쓴다. 둘 다 줄(row), 펭귄(character), 말풍선(bubble) div(like 상자)를 만들어서 하나로 묶은 다음 화면에 붙인다.

### 개념 5
이름: appendChild
내가 이해한 뜻: 만든 태그를 다른 태그 안에 넣는 명령. 상자 안에 상자를 넣는 것과 같다. 채팅 화면 안에 들어가야 비로소 화면에 보인다.
우리 프로젝트에서 사용된 곳: addMessage()와 showTyping()에서 펭귄과 말풍선을 줄(row) 안에 넣고, 그 줄을 채팅 화면(messagesEl) 안에 넣는다.


## 오늘 발생한 오류

오류 또는 문제: 자바스크립트가 아예 작동하지 않았다.
원인: addMessage를 호출할 때 소괄호 ( ) 대신 중괄호 { }를 썼다. 문법 오류가 한 줄만 있어도 JS 전체가 멈춘다는걸 알았다. 저거 하나 잘못됐다고 다 멈춰버렸다..ㅠ
어떻게 해결했는가: addMessage{ } 를 addMessage( )로 바꿨다.
