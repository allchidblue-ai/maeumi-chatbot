# 마음이 챗봇 3회차 학습 기록

## 1. 오늘 만든 기능
오늘은 프론트엔드와 Python FastAPI 서버를 연결했다.

## 2. 프로그램 흐름
사용자가 메시지를 입력하면:
1. sendMessage() 함수가 입력값을 text로 변수 처리함
2. 그리고 그 변수처리된걸 fastapi로 보낼 수 있는 함수에 넣음
3. fetch가 그 그 text를 json상자에 넣어서 fastapi에게 실행요청을 보냄
4. fastapi가 메세지를 받은 뒤 답변을 형성함
5. 그 답변을 다시 json 상자에 싸서 보냄, fetch가 답변을 다시 받아옴.
6. js에서 답변을 js가 사용할 수 있는 형태로 바꿈
7. 그 중 reply 즉 답변만 꺼내옴
8. 그런뒤 답변과 말풍선을 채팅화면에 띄움

## 3. 오늘 새로 알게 된 개념
### FastAPI
- Python으로 API 서버를 만들 수 있게 해주는 개발도구. 요청을 받고 데이터를 처리한 뒤 응답을 보내는 기능을 구현할 수 있다.

### API
- 서로 다른 프로그램이 정해진 규칙에 따라 데이터를 주고받을 수 있도록 만든 통로. 이번 프로젝트에서는 프론트엔드가 FastAPI 서버에 메시지를 보내고 답변을 받는 데 사용했다.

### JSON
- 프론트엔드와 백엔드가 데이터를 주고받을 때 사용할 수 있는 데이터 형식. 이번 프로젝트에서는 사용자의 메시지와 챗봇의 답변을 JSON 형식으로 전달했다.

### fetch()
- JavaScript에서 서버에 요청을 보내고 응답을 받아올 수 있게 해주는 함수. 이번 프로젝트에서는 사용자가 입력한 메시지를 서버에 보내고, 서버가 반환한 답변을 받아오는 데 사용했다.

## 6. 2회차와 3회차의 가장 큰 차이
- 2회차때는 서버없이 그냥 정해진 답변만 툭 툭 내놓았다면 3회차때는 서버를 만들고 통신이 잡히는지 확인하고 서버가 만든 답변을 내놓았다. 답변을 js가 직접 생성하는 것이 아닌 python에서 답변을 생성한다.
